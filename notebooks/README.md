# ノートブック（任意の教材）

| ファイル | 中身 | 所要 |
|---|---|---|
| `はじめてのPWSCup.ipynb` | 配布データで**加工（防御）と攻撃を1周ずつ体験する** | 20〜30 分 |
| `採点のしくみ.ipynb` | **得点がどう決まるか**——4観点が何を測っていて、どの操作で点が上下するか | 15〜20 分 |

> **これは任意の教材です。** ルールと提出フォーマットの正本は**ルールブック**と
> `../participant_data/sample_submissions/` です。食い違ったらルールブックが正しいと考えてください。
> 提出物は CSV とテキストファイルだけなので、**Python 以外の言語・ツールで作ってもかまいません**
> （自己採点器・検証器を動かすには Python か Docker が要ります）。

## 動かし方

環境は `starter/` に一本化しています（採点器と同じ版のライブラリで動くので、
ノートブックの中で出る点数がそのままサーバの点数になります）。

[uv](https://docs.astral.sh/uv/) を使う場合（推奨）:

```sh
cd starter
uv sync --extra notebook
uv run jupyter lab ..
```

pip を使う場合:

```sh
cd starter
python -m venv .venv && . .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -e ".[notebook]"
jupyter lab ..
```

ノートブックは `../participant_data/` のデータを読みます（zip を展開しただけの配置でも動くように、
データの場所は自動で探します）。

## 中身

**はじめてのPWSCup.ipynb**

1. 配布物の一覧を確認する
2. データの形と、転帰3列（`time` / `onset` / `death`）＝打ち切りの読み方
3. 素朴な匿名化をして `C.csv` を作る
4. 自己採点して「4つの観点のうちどれが一番低いか」を見る
5. 素朴な攻撃をして `F_mia.csv` / `F_aia.csv` を作る
6. AIA の得点＝「対照と比べて超過した分」の計算を実際に回してみる

**採点のしくみ.ipynb**

1. 総合得点＝ `min(有用性, 匿名性)`、有用性＝4観点の `min`
2. 加工の型を5つ作って、どこが崩れるかを比べる
3. **一番低い観点以外を直しても点は上がらない**ことを実演する
4. 4観点それぞれの内訳を開ける（希少を消すと 0 になる、など）
5. ノイズの強さを振って、点数がどう崩れるかを描く
6. 匿名性の目盛りと、自分の `C` に自分で MIA を撃つ自己診断
